# NOW

## 지난 묶음: 5시간 사용량 → 주간 사용량 (끝남)

Claude가 5시간 한도를 없애서 세션 기록의 `usage`에는 `ctx`와 `7d`(kind `seven_day`)만 온다. 5시간을 보던 곳을 모두 주간으로 옮겼다.

- 코어 링, 주간 85% 경고(누르면 이번 주 목록), 패널 줄의 `주간 ≈N%`.
- 플러그인 `trackSpend`가 `seven_day`의 `resetsAt`을 창으로 쓴다. 세션별 비용이 주간 리셋까지 쌓인다.
- 위젯은 7일 안의 세션 파일을 모두 읽는다(캐시 기록은 1시간 안의 파일만). 끝난 세션도 주간 합계에 들어간다.
- 패널 맨 위 주간 줄을 누르면 이번 주 많이 쓴 세션 목록(최대 8개, 끝난 세션은 흐리게).
- 문구 3개 언어, README 3개 언어판과 그림(`week.png` 새로 추가) 갱신.

## 알아 둘 것

- 몫은 비용 비중으로 나눈 추정치다. 웹이나 다른 기기에서 쓴 양은 세션별로 나눌 수 없다.
- 적용하는 순간 각 세션의 기준이 새 창으로 바뀌어 0부터 센다. 이번 주 목록은 다음 주간 리셋부터 한 주 전체가 정확하다.
- 끝난 세션의 이름은 앱 세션 제목을 한 번 찾아 쓰고, 없으면 프로젝트 폴더 이름이다. 같은 폴더 세션이 여럿이면 이름이 겹칠 수 있다.
